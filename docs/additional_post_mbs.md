# Post-click Micro-Behaviors (Post-MBs) in ERMB

Post-click interactions occur in single-column Waterfall Pages (WP) and Product Detail Pages (PDPs), which provide richer interactive elements and detailed item metadata. These post-click engagements yield more granular signals for inferring users' intent, as the expanded interface enables deeper exploratory behaviors. In total, the ERMB dataset contains more than one hundred post-MBs, grouped by different user interaction modules.

## Typical Post-MBs

| Feature Group | Feature Name | Definition |
|---|---|---|
| Product Detail Page | Product Detail Page Dwell Time | Total time spent on the product detail page |
| | Swipe Down | Whether the user swiped down after entering the product detail page |
| | Recommend-Tab Clicks | Number of clicks on the "recommend" tab to view more items |
| Reviews & Ask | Review Tag Clicks | Count of clicks on review tags |
| | Review Views | Count of views of item reviews |
| | Ask Everyone Entry Clicks | Count of entering the "Ask Everyone" details page |
| Item Detail | Product Detail Image Clicks | Number of clicks on product detail images |
| | Image Zoom-Ins | Number of times the user zoomed in on images using two fingers |
| Others | Share | Whether the user initiated a share |
| | Service Module Clicks | Count of viewing service guarantees |
| | Live Chat Clicks | Count of clicks to initiate customer support live chat |
