# ERMB Dataset Files

The ERMB dataset files and detailed field descriptions will be released in this directory.

Each impression sample contains:

1. Conventional user/item/context features;
2. Behavior sequence features;
3. More than one hundred micro-behavior signals spanning both pre-click cues and post-click activities.

Rigorous anonymization protocols, including identifier hashing and attribute generalization, have been applied to ensure data privacy compliance.
